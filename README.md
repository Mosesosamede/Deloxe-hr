# Deloxe HR

> **Innovative Human Resource Consulting — Where Ambition Meets Opportunity.**

Deloxe HR is an enterprise-grade Human Resource consulting platform designed to streamline talent sourcing, organizational management, regulatory compliance, and career development pipelines. Combining an elegant minimalist aesthetic with responsive interactive tools, Deloxe HR serves as the primary hub for companies looking to optimize their workforce and individuals looking to scale their careers.

---

## 🚀 Core Offerings & Modules

### 💼 1. Enterprise HR & Talent Services
* **Recruitment & Talent Sourcing:** Automated vetted talent search engine mapped against custom organizational requirements.
* **HR Audit & Compliance:** Streamlined workspace health checks, regulatory localized reports, and risk auditing standards.
* **Performance Management:** Structural appraisal templates, modern feedback mechanisms, and progress trackers.

### 🎓 2. Internship & Graduate Development Services
* **Internship Management for Companies:**
  * Sourcing qualified, pre-screened interns.
  * End-to-end program management and coordination.
  * Structural onboarding, dedicated feedback loops, and evaluation logs.
* **Graduate Internship Preparation:**
  * Targeted role preparation and skill alignment.
  * Intensive, hands-on career-readiness training.
  * Strategic matchups with ideal host companies.

### 💳 3. Dynamic Subscription & Pricing Matrix
* **Flexible Scale Tiers:** Selectable growth levels customized per plan to suit growing startups up to multinational corporations.
* **Flexible Cycles:** Switchable Monthly, Quarterly, and Biannual billing intervals.
* **Multi-Currency Platform:** Real-time localized exchange rate calculations supporting `USD`, `EUR`, `GBP`, `CAD`, `AUD`, and `NGN` symbols.
* **Interactive Checkout Engine:** Elegant confirmation modal providing instant point-of-contact capture, custom requirements submission, and subscription validation checks.

## 🛠️ Technology Stack

Deloxe HR is built using a modern, performant, and visual-first toolkit:

* **Framework:** [Next.js](https://nextjs.org/) (App Router & modern Server/Client Component design patterns)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/) (Fluid utilities and high-contrast typographic layout scaling)
* **Animations:** [Motion](https://motion.dev/) (Staggered entrances, fluid mobile carousels, and persistent hover active state scaling)
* **Icons:** [Lucide Icons](https://lucide.dev/) (Consistent, clean stroke representations)
* **Smooth Scrolling:** [Lenis](https://github.com/darkroomengineering/lenis) (Sleek user viewport scrolling mechanics)

## 💻 Technical Setup

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your local environment.

### Getting Started

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Run Development Server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

3. **Build Code for Production:**
   ```bash
   npm run build
   ```

4. **Start Production Service:**
   ```bash
   npm run start
   ```

5. **Linting Verification:**
   ```bash
   npm run lint
   ```
